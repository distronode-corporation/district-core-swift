# Contract fixtures

Recorded responses from the District AI API: the wire-format contract the apps that use
this package are built against. They are generated by the District AI service's own test
suite, which checks its real responses against them byte for byte, and are copied here
unchanged.

- `mobile/` mirrors the service's `contracts/mobile` set, the shapes the iOS and Android
  apps decode. `ContractFixtureTests` reads it (see [mobile/README.md](mobile/README.md)).
- `desktop/` mirrors the service's `contracts/desktop` set, the shapes only the desktop
  clients use (telemetry events, the telemetry token, call hang-up, desktop device
  registration and the scheduling hand-off). `DesktopContractFixtureTests` reads it.

Both are updated by pull request when the service changes them, file for file, with no
edits. Edits by hand are not accepted: if a fixture looks wrong, or a model and the
service disagree about a response, open an issue.

The data is fictional: phone numbers are in the 555 range, and the only real host names
and addresses are the service's own public ones (the website, the media server and the
notification sender). The sample message bodies contain dashes; this directory is exempt from
the dash rule of `scripts/check-public-hygiene.py` because the files are copies.
