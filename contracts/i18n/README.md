# I18n contracts

The website's localization facts, recorded for the native apps so they never retype them.
Generated by `src/lib/contracts/__tests__/i18n-contracts.test.ts` from the real modules and
compared byte for byte; regenerate with `CONTRACTS_UPDATE=1 npx vitest run <that file>`.

| File | What it holds |
|---|---|
| `api-errors.json` | Every API error code (`code` in the body, else the `X-Distronode-Error-Code` header) with the sentence the portal renders in English and French. The two list codes carry `{items}` plus a form without the list. |
| `wire-vocabulary.json` | Enumerated wire values a screen shows (call status, direction, type, sentiment, disposition, transfer outcome, funnel stages, member roles, regions), where each is defined, and the portal's labels (`fr: null` where the portal has none). Also the server's English placeholder strings. Wire values never localize; only their labels do. |
| `format-vectors.json` | Inputs and outputs of `src/lib/i18n/money.ts`, `src/lib/i18n/format.ts` and the two duration formatters, in English and French. A category the website has no function for is recorded with `"source": null`. |

An app opts in by carrying this directory as `contracts/i18n/`; from then on
`drift:app_contracts` (`scripts/check-app-contracts.mjs`) holds its copy to these bytes.
